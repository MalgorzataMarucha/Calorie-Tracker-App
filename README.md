# Calorie Tracker App
A desktop calorie tracker inspired by Fitatu, designed to calculate calories and monitor daily meal consumption.

## Features
- **Main Menu**: An overview displaying key nutritional information for the current day.
- **Meal Management**: Search and add meals, or create custom food items to save and reuse later.
- **Goals & Settings**: Set daily macro targets (calories, protein, fats, and carbohydrates) and track statistics.
- **Calendar**: Navigate through different dates to review historical meal plans.
- **Data Persistence**: Uses a local JSON file for lightweight, database-free data storage.
